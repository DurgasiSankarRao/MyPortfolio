# 🌐 Personal Portfolio Website

A modern, responsive personal portfolio website built to showcase my skills, projects, and contact information in a clean and professional way.

This portfolio highlights my web development journey, hands-on projects, and provides an easy way for recruiters or collaborators to connect with me.

---

## ✨ Features

- Responsive design (mobile, tablet, desktop)
- Clean and modern UI
- Smooth scroll and reveal animations
- Project showcase with live links
- Functional contact form (Formspree)
- Downloadable resume
- Social media integration

---

## 🛠️ Tech Stack

- **HTML5** – Structure & content  
- **CSS3** – Styling, layout, responsiveness  
- **JavaScript (ES6)** – Interactivity & animations  
- **ScrollReveal.js** – Scroll-based animations  
- **Formspree** – Contact form handling  

---

## 📂 Sections Included

- **Home** – Introduction and call-to-action  
- **About** – Short professional overview  
- **Skills** – Technologies and proficiency  
- **Projects** – Real-world project demos  
- **Contact** – Email form & social links
